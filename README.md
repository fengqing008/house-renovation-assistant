# 全能房屋装修助手 · house-renovation-assistant

> 从风格判定到效果图、从装修方案到分档预算的一站式家装顾问 · **Skill v2.6.0**

把家装这件高度依赖经验、报价水很深的事，拆成**可核对、可比较、可落地**的六步：
**风格判定 → 现状识别 → 方案设计 → 效果图 → 费用预算 → 成文交付**。

## 三大专家级能力

| 能力 | 落点 | 支撑 |
|------|------|------|
| 设计达资深设计师水准 | 人体工学尺度、点位系统、照明设计、暖通环境、适老适幼 | `references/10–14` + `layout_check.py` |
| 效果图达可印刷高清级 | 专业机位提示词、4× 无损放大、出图质检 | `references/07` + `prompt_builder.py` / `upscale_bridge.py` / `render_check.py` |
| 预算达审计级 | 量价分离清单、报价单审计 | `references/04/16` + `budget_calc.py` / `quote_audit.py` |
| 空间布局可视化 | 平面 2.5D 彩平 + AI 手绘插画彩平 + 精装 PDF | `plan_render.py` + `pdf_render.py` |

## v2.6 新增：入口三选项分诊

1. **给小区信息** — 给「小区名称 + 楼栋号 + 建筑面积」，自动全网检索该小区公开户型图并做面积交叉核对（±5%），据此设计；
2. **上传户型图** — 直接上传户型图 / 设计图，识别房屋现状后照图设计；
3. **逐步询问** — 什么都不给，由问卷一步步采集需求。

## 快速开始

```text
输入：万象春天 3 号楼 118㎡，西安，想要奶油风，家里有老人和小孩，帮我出个装修方案和预算。

产出：
1. 入口分诊 → 全网检索小区公开户型图 → 面积交叉核对（±5%）
2. 需求澄清（五维）与假设清单
3. 风格判定（含冲突检测与判定理由）
4. 房屋现状档案（未识别项标【待核】）
5. 逐空间设计方案（布局 + 尺寸校核 + 点位 + 照明 + 适老适幼）
6. 效果图组图（每间房 2 视角，约 20 张，统一 1400×800，4× 放大）
7. 量价分离三档预算（经济型 / 舒适型 / 轻奢型）+ 单方造价 + 易超支项
8. 单文件 HTML 成果页 + 精装 Word / PDF 方案
```

## 适用 / 不适用

**适用**：新房整装、旧房改造、局部翻新、预算测算、装修报价单审计、适老适幼设计。

**不适用**：CAD 施工图与结构安全计算、工程报建与竣工验收、大体量公装、定额套价与工程结算审减。

**红线**：不碰结构安全（不提供拆承重墙、破坏外立面方案）；不承诺绝对价格（预算为估算区间）；不伪造数据（无来源价格标【待核】）；户型图仅作设计参考。
