# 06 · 材料与工艺（清单与环保等级）

> S3 写材料清单与工艺要点时读。**环保等级必须写明依据，不写"环保材料"了事。**

## 一、主材清单（按空间）

| 空间 | 主材 | 选型要点 |
|------|------|---------|
| 全屋地面 | 瓷砖/木地板 | 客餐厅瓷砖选耐磨度 PEI≥4；卧室木地板选环保等级 |
| 墙面 | 乳胶漆/艺术漆/壁布 | 乳胶漆看 VOC 与耐擦洗次数（≥5000 次） |
| 门窗 | 断桥铝/木质门 | 断桥铝型材壁厚≥1.4mm（国标）；隔音用双层中空 |
| 卫浴 | 马桶/淋浴/浴室柜 | 马桶选虹吸式静音；地漏选深水封/T 型防返臭 |
| 厨房 | 台面/柜体/烟灶 | 台面石英石/岩板；烟机风量≥17m³/min |
| 灯具 | 筒灯/轨道灯/灯带 | 显色指数 Ra≥90；无频闪 |

## 二、辅材清单

水泥砂浆、防水涂料（柔性/刚性）、板材（木工板/多层板/石膏板）、胶粘剂、五金（合页/滑轨/拉手）、电线（国标铜芯，2.5㎡/4㎡）、水管（PPR，打压≥0.8MPa）、腻子、网格布。

> **辅材是最容易被"偷工减料"的环节**，方案中应写明品牌档次而非"同等品质"。

## 三、环保等级（核心，依据 GB 18580-2017）

| 等级 | 甲醛释放限量 | 说明 |
|------|------------|------|
| **E1** | ≤0.124 mg/m³ | 国标最低准入（GB 18580-2017 强制） |
| **E0** | ≤0.050 mg/m³ | 优于国标 |
| **ENF** | ≤0.025 mg/m³ | 无醛级，最高标准 |

**建议**：儿童房、卧室、密闭空间选 ENF 或 E0；预算有限时至少 E1 且有检测报告。
**依据**：GB 18580-2017《室内装饰装修材料 人造板及其制品中甲醛释放限量》；GB/T 18883-2022《室内空气质量标准》（甲醛≤0.08mg/m³，TVOC≤0.6mg/m³）。

## 四、关键工艺要点（写进方案）

1. **水电**：路线横平竖直，强弱电分槽，线管穿线率≤40%，隐蔽工程拍照留档，打压试验 0.8-1.0MPa 保压 30min。
2. **防水**：卫生间墙面防水上返≥1.80m（淋浴区），其他≥0.30m；闭水试验 24h 无渗漏。
3. **贴砖**：留缝 2-3mm（防热胀），空鼓率墙砖≤5%，阳角用不锈钢护角或海棠角。
4. **吊顶**：龙骨间距≤1.2m，石膏板接缝错开并嵌缝处理，防裂。
5. **油漆**：腻子打磨 2-3 遍，乳胶漆一底两面，环境温度≥5℃、湿度≤80%。
6. **定制**：柜体板材厚度 18mm，背板 9mm，封边严密（封边差=甲醛释放源）。

## 五、环保与通风

- 装修后**空置通风≥3 个月**再入住，有老人小孩/孕妇建议 ≥6 个月并做空气质量检测。
- 活性炭、绿植、新风系统可辅助，但不能替代通风。
- 检测依据 GB/T 18883-2022，建议委托有 CMA 资质机构。

## 六、避坑

- "零甲醛"是营销话术，国标只到 ENF（≤0.025mg/m³），不存在绝对零。
- 板材环保不等于全屋环保（胶、油漆、软装同样释放）。
- 低价全包常省辅材与五金，务必落进合同明细。
