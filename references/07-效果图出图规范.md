# 07 · 效果图出图规范（S4 · 高清级 v2）

> 链路：`scripts/prompt_builder.py`（构提示词）→ `image_gen`（出图）→ `scripts/upscale_bridge.py`（4× 无损放大）→ `scripts/render_check.py`（质检）。
> **效果图仅示意风格与氛围，不是施工依据**（图注声明见 FM-03）。

## 一、出图矩阵（空间 × 机位）

每空间给**多机位**（提示词库内置，见 `prompt_builder.py` 的 CAMERA 库）：

| 空间 | 机位（焦距·机位高·构图） | 必出 |
|------|------------------------|------|
| 客餐厅 | 入户视角(24mm·1.5m)、沙发区平视(35mm·1.2m·45°)、电视墙正对(35mm·1.5m) | ✅ 至少 2 张 |
| 餐厅 | 餐桌主视角(35mm·1.4m)、俯视全局(28mm·1.6m·45°) | 建议 |
| 主卧 | 床头全景(24mm·1.4m)、床尾平视(35mm·1.2m) | ✅ |
| 次卧/儿童房 | 全景(24mm·1.2–1.4m) | ✅ |
| 厨房 | 门口俯视全局(28mm·1.6m·45°)、操作台平视(35mm·1.4m) | ✅ |
| 卫生间 | 干区全景(24mm·1.4m)、淋浴区视角(28mm·1.5m) | 建议 |
| 阳台/玄关/书房 | 全景(24–28mm·1.4–1.5m) | 按需 |

> 户型 ＞150㎡ 按空间分区出图；**人视角机位高 1.2–1.6m**（模拟站立/坐姿视高），避免俯拍失真。

## 二、提示词结构（六要素，v2 增强）

```
[空间] + [风格] + [关键色hex/色名] + [材质（含物理细节）] + [家具布局]
+ [灯光氛围] + [机位（焦距·机位高·构图）] + [画质] + 〔负向〕
```

**示例（奶油风客厅·入户视角）**：
> 客厅室内设计效果图，奶油风，奶油杏#F1E4D6与浅燕麦#D9C7B0，奶油哑光砖、艺术涂料弧形墙、亚麻布艺、羊羔绒，微水泥质感墙面柔光、亚麻布艺粗织纹理、圆弧倒角柔和高光，圆弧倒角沙发、原木茶几，暖光3000K、灯带洗墙、云朵灯，温馨治愈、柔和放松，自然采光充足，24mm 广角镜头，机位高 1.5m，从入户方向框住客餐厅全景，超写实建筑渲染，真实全局光照，材质细节清晰，物理正确阴影，专业室内摄影，建筑可视化，高清，电影级画质。
> 负向：变形, 扭曲, 畸变, 错误透视, 多余手指, 文字, 水印, logo, 低分辨率, 模糊, 过曝, 杂乱 …

## 三、清晰度（"高清级"如何真正兑现）

| 环节 | 参数 | 说明 |
|------|------|------|
| 出图分辨率 | 默认 `1664*928`（16:9）；竖构图空间 `1024*1280` | `--size` 指定，传给 `image_gen` 的 width/height |
| 画质词 | 超写实渲染/真实光影/材质细节 | 提示词内的**风格描述**，不等于真实分辨率 |
| **放大** | `upscale_bridge.py --scale 4` | 4× 放大，长边可达 6000px+，**可印刷级** |
| 门印制门槛 | 长边 ≥3000px | 300dpi 下 A4 宽约 2480px，达标即可打印 |
| 质检 | `render_check.py --min-side 3000` | 放大后复检 |

> ⚠️ 提示词里写"8K"只是风格词，**真实高清必须靠分辨率参数 + 放大链路**，两者不可混为一谈。

## 四、批次一致性（同一户多图不"精神分裂"）

- **固定 seed**：`--seed 20261006`（同一户所有空间共用），保证风格与色调统一。
- **统一色板**：`--json` 输出含 `palette`（该风格 hex 列表），各图共用。
- **同风格词**：同一户不同空间用同一风格名与材质词，禁止客厅奶油、卧室工业的割裂。

## 五、出图纪律

1. **一图一空间一机位**：不在一张图塞多个功能视角。
2. **色号入提示词**：把 hex 转色名写进提示词，与方案色彩一致。
3. **尺寸声明**：图注必写"效果图仅示意风格与氛围，尺寸与工艺以方案及施工图为准"（FM-03）。
4. **不生成违规内容**：不生成拆承重墙、外立面改造等违规画面。
5. **真实参考图并行**：`search(format=image)` 检索真实装修案例图并列展示，注明来源。

## 六、多后端降级链（image_gen 不可用时）

```
① image_gen（首选，参数化分辨率）
   ↓ 不可用
② pollinations-image / generate-image（免费后端，出图后同样走 upscale_bridge 放大）
   ↓ 不可用
③ 仅输出「提示词卡片」+ 检索真实参考图，注明"效果图未生成，附提示词与参考图"
```

降级时必须**显式说明当前通道**，不得静默降级。

## 七、出图后质检（render_check.py）

- [ ] 分辨率：长边 ≥1536px（出图）/ ≥3000px（放大后）？
- [ ] 比例：横 1.4–1.9 / 竖 0.65–0.85？
- [ ] 亮度：无过曝（均灰度 ≤230）、无过暗（≥40）？
- [ ] 对比度：灰度标准差 ≥20（不发灰）？
- [ ] 文件：≥80KB？
- [ ] 空间与风格是否匹配方案？色彩是否与方案色号一致？
- [ ] 多空间是否风格冲突？图注是否含"仅示意"声明？

```bash
python3 scripts/render_check.py --dir renders/ --min-side 1536
```

## 八、放大链路（upscale_bridge.py）

```bash
# 单张
python3 scripts/upscale_bridge.py --input renders/客厅_入户视角.png --outdir out_upscaled --scale 4
# 批量
python3 scripts/upscale_bridge.py --dir renders/ --scale 4
```

- 通道①：**远程 AI 放大**（优先调用 ai-upscaler / Pollinations Kontext，真增强）；
- 通道②：**本地插值放大**（PIL LANCZOS 4× + 锐化，离线兜底，**非 AI 增强**，输出会标注）；
- 输出命名 `<原名>_4x.png`，stderr 打印实际通道，交付时如实说明用的是哪条通道。
