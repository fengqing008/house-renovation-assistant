# 14 · 适老适幼与无障碍（安全优先设计）

> **用途**：当家中有**老人、儿童、孕妇或行动不便者**时，S3 方案必须叠加本表的安全设计。这类家庭的安全隐患往往藏在"标准设计"里（如尖锐直角、过滑地面、无扶手、够不着的开关），须专项校核。
> **依据**：GB 50763-2012《无障碍设计规范》、GB/T 50340-2016《老年人居住建筑设计规范》、GB 50642-2011《无障碍设施施工验收及维护规范》，以及儿童安全通行做法。
> **触发**：需求澄清五维（见 SKILL.md）"对象"维度问及老人/小孩/孕妇/宠物时，自动加载本表。

## 一、适老设计（老人居家安全）

### 1. 关键尺度（轮椅/助行器兼容）

| 项目 | 要求 | 说明 |
|------|------|------|
| 门净宽 | ≥0.80m（轮椅） | 常用门 |
| 通道净宽 | ≥0.90m（轮椅通行），≥1.20m（回转） | GB 50763-2012 |
| 轮椅回转空间 | 直径 ≥1.50m | 卫生间/卧室 |
| 地面高差 | 无门槛或 ≤0.015m 倒角 | 防绊倒 |
| 防滑 | 摩擦系数（干态）≥0.6、湿态 ≥0.5 | 卫生间/厨房重点 |

### 2. 安全设施

| 部位 | 设施 | 高度 |
|------|------|------|
| 马桶旁 | 扶手 | 距地 0.70m |
| 淋浴区 | L 型扶手 + 折叠淋浴椅 | 0.70m |
| 浴缸/淋浴 | 防滑垫 + 坐凳 | — |
| 走廊/床头 | 夜灯（感应、低位） | 0.30–0.40m 或地脚灯 |
| 楼梯 | 双侧扶手 + 防滑条 + 踏步照明 | 扶手高 0.85–0.90m |
| 厨房 | 拉篮式地柜（避免深蹲） | — |

### 3. 适老要点

- **照明**：全屋提亮（老人需光量约年轻人 2 倍），走道/卫生间设**感应夜灯**；避免强对比眩光。
- **开关插座**：高度适中（开关 0.90–1.10m，便于坐姿触及）；选大面板、位置明显。
- **家具**：避免过软（起身困难）；床高 0.45–0.50m 便于起坐；椅子带扶手。
- **色彩**：避免大面积深色（视觉压抑）；地面与墙面**明度差**清晰，便于识别边界。
- **智能**：语音控制、紧急呼叫、燃气/烟雾报警。

## 二、适幼设计（儿童安全与成长）

### 1. 安全

| 隐患 | 措施 |
|------|------|
| 家具尖角 | 圆角处理 / 防撞角（含茶几、柜边） |
| 抽屉/柜门夹手 | 阻尼铰链 + 安全锁扣 |
| 攀爬跌坠 | 上铺护栏 ≥0.30m；窗装限位器/防护栏 |
| 插座触电 | 插座保护盖 / 带安全门插座 |
| 玻璃 | 钢化/夹胶玻璃；柜门用亚克力替代 |
| 板材环保 | 儿童房选 **ENF 级板材**（GB 18580-2017，见 `06`） |
| 甲醛 | 儿童房空置通风 ≥6 个月 + CMA 检测 |

### 2. 成长性

- **可成长家具**：可升降书桌椅（护眼、护脊）；床选可加长/可拆护栏款。
- **护眼照明**：儿童房/书桌 **无频闪 + Ra≥90 + 照度 300lx**（见 `12`）。
- **活动空间**：地面活动空间 ≥1.5㎡；预留玩耍区。
- **收纳**：低矮开放格便于儿童自主取放；玩具分类收纳。
- **色彩**：活泼但不刺激（避免高饱和大面积）。

## 三、无障碍与通用设计（可用性提升）

- **通用设计原则**：同一空间同时服务老人、儿童、成人（如可调高度台面、双高度扶手）。
- **卫生间**：三分离便于多人同时使用；干湿分离防滑。
- **地面**：通铺无高差（避免门槛石绊倒，用同色收边）。
- **把手**：长条拉手替代圆球拉手（好发力）；按压式优于旋转式。
- **照明开关**：双控/感应，减少走动。

## 四、适老适幼方案输出格式

在标准方案基础上，**单列"安全专项"章节**：

```text
安全专项设计（家有一老一幼）
【适老】
- 卫生间：马桶侧扶手 0.70m、淋浴折叠椅、防滑砖（湿态≥0.5）、感应夜灯
- 全屋：无门槛通铺、开关降至 1.00m、走廊双侧扶手（如需要）
- 照明：全屋照度较常规 +50%，走道地脚感应灯
【适幼】
- 儿童房：ENF 板材、圆角家具、可升降书桌、护栏≥0.30m
- 全屋：插座安全门、玻璃钢化、窗限位器、阻尼铰链
【共性问题】
- 地面防滑优先、通铺无高差、亮度对比清晰
```

## 五、避坑

1. **只做"儿童房"不做"全屋安全"**：儿童活动范围是全屋，插座/玻璃/尖角全屋排查。
2. **老人房照明不足**：老人视力下降，照度需加倍。
3. **门槛石绊倒**：老人/轮椅家庭尽量无高差。
4. **亮面砖过滑**：湿区选防滑砖，禁用抛光砖。
5. **上铺无护栏**：儿童坠床事故高发。
6. **环保级别降标**：儿童房务必 ENF，勿为省钱用 E1。
7. **开关过高/过低**：老人小孩都够不着。
