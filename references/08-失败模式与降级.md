# 08 · 失败模式与降级（质检与异常）

> 交付前用 `scripts/renovation_check.py` 自检；异常时按本表降级。

## 一、失败模式库（FM）

| 编号 | 失败模式 | 触发信号 | 处置 |
|------|---------|---------|------|
| FM-01 | 三档预算只改数字不改材料 | 三档材料清单雷同 | 重做，体现品牌/工艺/环保等级档次差异 |
| FM-02 | 无视承重墙乱拆改 | 方案含拆墙/改结构 | 拦截，提示《住宅室内装饰装修管理办法》（建设部令第110号）禁止拆除承重墙，须报备 |
| FM-03 | 效果图当施工依据 | 图注无声明 | 补"仅示意"声明 |
| FM-04 | 地区单价一套用全国 | 未按城市系数校准 | 按 `04` 城市系数校准，或标【待核】 |
| FM-05 | 环保等级含糊 | 只写"环保板材" | 补 E1/E0/ENF 与 GB 18580-2017 |
| FM-06 | 预算漏项（低价陷阱） | 报价未含拆改/水电/管理费 | 按 `04` 13 项清单逐项核对补全 |
| FM-07 | 户型尺寸臆测 | 无平面图却给出精确尺寸 | 全部标【待核】或转问答采集 |
| FM-08 | 金额未千分位 | 出现 128000 而非 128,000 | 全局格式化 |
| FM-09 | 风格与用户禁忌冲突 | 用户选"不接受深色"却出工业风 | 重新打分并排除禁忌风格 |
| FM-10 | 工期表逻辑倒置 | 油漆排在水电前 | 按 `05` 工序逻辑重排 |
| FM-11 | 报价缺项未识别 | 报价单漏拆改/水电/管理费未提示 | 跑 `quote_audit.py` 出缺项清单（见 `16`） |
| FM-12 | 单价/量差异常未标红 | 单项单价或工程量显著偏离基准未提示 | 跑 `quote_audit.py`，超 ±30%/±20% 标红 |
| FM-13 | 效果图未达高清级 | 长边＜1536px 或未放大 | 走 `upscale_bridge.py` 4× 放大 + `render_check.py` 复检 |
| FM-14 | 尺寸凭感觉给精确值 | 未按人体工学/规范校核 | 跑 `layout_check.py`，未实测标【待核】 |
| FM-15 | 无图臆测户型 | 路径 A 未检索到却给出具体户型 | 明确告知未检索到，降级逐步询问（路径 C），不得臆测 |
| FM-16 | 户型图面积不符仍采用 | 图中面积与用户所给偏差 >±10% | 列候选让用户指认或弃用，提醒可能非本户型 |
| FM-17 | 户型图当实测依据 | 成果未声明"以实际测绘为准" | 补来源链接与"以实际测绘/物业确认为准"声明 |

## 二、降级路径

| 场景 | 降级动作 |
|------|---------|
| image_gen 不可用 | 出提示词卡片 + 真实参考图（见 `07`） |
| 无平面图 | 问答采集房间清单，尺寸标【待核】 |
| 无当地信息价 | 全国区间参考 + 提示校准 |
| 预算＜最低档 | 触发预算冲突提醒，给降档建议（局部/分阶段/换材质） |
| html 基座缺失 | 退化为 Markdown + Word，说明原因 |
| 上传图模糊 | 请补传或改问答，不臆测 |

## 三、交付前自检清单（renovation_check.py 依据）

- [ ] 五维输入是否齐备？缺项是否已列"假设清单"？
- [ ] 风格判定是否有理由与冲突提醒？是否经用户确认（确认门①）？
- [ ] 平面图是否已识别？尺寸未实测是否标【待核】？
- [ ] 三档预算材料档次是否有差异（FM-01）？
- [ ] 是否按城市系数校准（FM-04）？
- [ ] 环保等级是否写明（FM-05）？
- [ ] 金额是否千分位（FM-08）？
- [ ] 效果图是否含"仅示意"声明（FM-03）？
- [ ] 是否触碰结构安全（FM-02）？
- [ ] 是否附"估算区间，非报价承诺"提示？
- [ ] 入口分诊是否走完？路径 A 检索到户型图是否做了面积核对与来源标注（FM-15/16/17）？

## 四、红线自检（任一命中即拦截）

- 拆除承重墙/剪力墙/梁柱方案 → 拒绝并说明。
- 伪造面积/价格/工程量 → 拒绝，标【待核】。
- 承诺绝对价格 → 改为区间 + "以合同为准"。
- 用于规避物业/主管部门监管 → 拒绝。

## 五、返工记录

每次返工记录到 `outputs/failure_modes`（FM 编号），沉淀经验；同一 FM 出现 ≥3 次须回写本文件。
