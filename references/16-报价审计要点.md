# 16 · 报价审计要点（审计师水准核价与校核）

> **用途**：把装修方案从"一张漂亮的方案"升级为"经得起逐项核价的方案"。本文件服务两个环节：
> ①**自检**——用 `budget_calc.py` 生成量价分离清单，逐项可核；②**审计**——用 `quote_audit.py` 拿装修公司报价单，查缺项/重复/单价异常/量差，出审减与风险清单。
> **依据**：装修行业通行报价实务、《住宅室内装饰装修管理办法》（建设部令第110号）、GB 50210-2018。
> **定位**：本技能提供**顾问级**核价与校核，不替代造价咨询机构出具的正式报告（见红线）。

## 一、为什么装修报价"水很深"——六个普遍问题

| 问题 | 表现 | 后果 |
|------|------|------|
| 缺项漏项 | 报价不含拆改/水电/管理费 | 后期增项，总价失控 |
| 重复计列 | 同一工序拆成多项、人工费与工序费重复 | 多付钱 |
| 单价虚高 | 单项单价高于市场 30%+ | 单方造价虚高 |
| 工程量注水 | 面积/延米/点位按上限甚至超标计 | 量差套钱 |
| 材料以次充好 | 报价"同等品质"、不写品牌型号 | 实际降标 |
| 工艺含糊 | 只写"常规工艺"不写标准 | 验收无据 |

> **审计的核心不是压价，而是让每一分钱对应可核对的数量×单价×品牌。**

## 二、量价分离核价法（本技能的核价引擎）

报价应满足：**合价 = 工程量 × 综合单价**，且：

1. **综合单价要能拆成"材料费 + 人工费 + 辅材/机械"** —— 只报一个总单价的，要求拆分。
2. **工程量要能对应图纸/现场**（面积、延米、点位、樘数），不接受"按套/按项包干"的模糊量。
3. **材料要写"品牌 + 型号 + 规格 + 环保等级"**，否则按基准档核价。
4. **三档（经济/舒适/轻奢）差异必须落在材料品牌与单价**，不是只改总数（对齐 FM-01）。

基准取值（`budget_calc.py`）：工程量按建筑面积推算（见 `04`），材料价全国参考、人工费按城市系数。

## 三、报价审计六查（quote_audit.py 的输出维度）

| 序 | 审计项 | 判定规则 | 处置 |
|----|--------|---------|------|
| 1 | **缺项** | 标准 15 分项中未出现 | 要求补列，否则视为后期增项风险 |
| 2 | **重复计列** | 同一分项名出现 ≥2 次 | 要求合并/删除重复 |
| 3 | **单价异常** | 综合单价偏离基准 ±30% | 高于要求说明理由；低于警惕降标 |
| 4 | **量差** | 报价量与估算量偏差 ±20% | 核对图纸与现场 |
| 5 | **低价套餐特征** | 总额＜基准 70% 且缺项 ≥4 | 预警"低价引流+增项"，要求闭口合同 |
| 6 | **风险提示** | 总额＞基准 140% | 核对是否虚高或含高档材料 |

## 四、必查的"高频陷阱"清单（逐条对照报价单）

- [ ] 拆改费是否含**垃圾清运与外运**（常另计）。
- [ ] 水电改造是**按实际发生**还是**按点位包干**？按实际易失控，建议点位包干 + 封顶。
- [ ] 是否含**管理费**（通常 5%–10%）、**设计费**、**税金**。
- [ ] 瓷砖/地板是否含**辅材（水泥砂浆、勾缝剂、找平）**？还是另算。
- [ ] 防水是否含**闭水试验**与**上返高度**。
- [ ] 全屋定制是否含**五金（铰链/滑轨/拉手）**与**安装**？封边工艺？
- [ ] 木门是否含**门套、五金、安装**。
- [ ] 乳胶漆是**一底两面**还是"两遍面漆"（少一遍底漆）。
- [ ] 吊顶是否含**龙骨、收边、造型**。
- [ ] 是否含**成品保护、开荒保洁**。
- [ ] 材料是否写**品牌型号**，还是"同等品质/知名品牌"。
- [ ] 增项规则是否明确（单价锁定？幅度上限？）。

## 五、审计结论与审减建议

审计报告给三类结论：

1. **补列项**：缺项按基准价估算，提示"若不补列，后期预计增项约 X 元"。
2. **核减建议**：重复计列、量差、单价虚高项，给出建议核减金额。
3. **风险等级**：低/中/高，高风险项（低价套餐、大面积缺项、无闭口条款）须重点谈判。

> **谈判抓手**：①要求"闭口合同/总价包干"；②单价锁定 + 增项单价不高于主合同；③材料品牌型号写进合同；④保留 5%–10% 质保金。

## 六、合规红线（审计方也要守）

- 不替代造价咨询机构出具的**正式造价鉴定意见**；
- 不编造市场价，未核实标【待核】；
- 不引导用户逃税（如要求不开发票）；
- 不主张恶意压价至**低于成本价**（易致偷工减料，反伤用户）。

## 七、快速用法

```bash
# 1. 先生成基准（量价分离）
python3 scripts/budget_calc.py --area 120 --city 西安 --tier 舒适型

# 2. 用装修公司报价单做审计
python3 scripts/quote_audit.py --csv 报价单.csv --area 120 --city 西安 --tier 舒适型

# 3. 方案/预算/效果图一致性核对
python3 scripts/consistency_check.py --plan 方案.md --budget 预算.md --renders renders/
```
