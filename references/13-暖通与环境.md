# 13 · 暖通与环境（新风 / 空调 / 地暖 / 隔音 / 防潮）

> **用途**：S3 方案的环境系统设计。暖通（采暖通风空调）与隔音、防潮决定了"住进去舒不舒服"，且多需**与硬装同步预埋**，事后几乎无法补做。方案须在拆改阶段前定稿。
> **依据**：GB 50736-2012《民用建筑供暖通风与空气调节设计规范》、GB 50118-2010《民用建筑隔声设计规范》、GB/T 18883-2022《室内空气质量标准》。
> **铁律**：①需预埋的系统（中央空调/新风/地暖）必须在方案阶段定，错过吊顶节点即无法补装；②层高是硬约束，做吊顶须先算剩余净高。

## 一、层高与吊顶余量核算（先算再设计）

| 系统 | 占用吊顶高度 | 说明 |
|------|-------------|------|
| 中央空调（风管机/多联机） | 250–350mm | 含冷凝水管坡度 |
| 新风系统（管道式） | 80–150mm | 主管道更厚 |
| 普通吊顶（石膏板+龙骨） | 80–120mm | — |
| 磁吸轨道嵌装 | 50–60mm | — |

> **净高公式**：装修后净高 = 结构层高 − 吊顶占用 − 地面找平/地暖（50–100mm）。
> GB 50096-2011 要求卧室/起居室净高 ≥2.40m（局部 ≥2.10m 且面积 ≤1/3）。**净高＜2.60m 慎做满吊顶 + 中央空调**，否则压抑。

## 二、新风系统

| 项目 | 参数 | 说明 |
|------|------|------|
| 新风量 | 住宅换气 0.5–1.0 次/h 或人均 ≥30m³/h | GB 50736-2012 |
| 类型 | 双向流（带热回收）优于单向流 | 热回收效率 60%–80% |
| 主管道 | 直径 100–150mm，走吊顶/梁下 | 需在吊顶前布管 |
| 风口 | 送风口与回风口对角布置 | 避免气流短路 |
| 适用 | 临街/雾霾/密闭户型/有过敏人群 | 不能替代开窗通风 |

> 新风的真实价值：①关窗也能换气（隔音+防尘）；②装修后加速散味。**但甲醛主要靠通风稀释**，新风是辅助，不是"除甲醛神器"。

## 三、空调系统

| 方案 | 适用 | 要点 |
|------|------|------|
| 分体壁挂/柜机 | 预算优先、局部使用 | 冷负荷估算 120–180 W/㎡ |
| 风管机（一拖一） | 追求美观 + 分区控制 | 需吊顶，检修口必备 |
| 中央空调（多联机/一拖多） | 大户型、整体美观 | 需吊顶 + 检修口；初投资高 |
| 地暖 | 冬季采暖，脚暖头凉 | 水地暖热水 35–45℃，盘管间距 150–300mm |

> **关键**：空调需**预留检修口**；冷凝水管须有**排水坡度**（≥1%），否则倒流漏水。冷负荷估算需按朝向、窗墙比、保温条件修正，本表为经验值，精确设计须专业计算。

## 四、通风与除湿

- **卫生间**：必设**排风扇**（风量 ≥100m³/h），暗卫需长排风；选带止逆阀防返味。
- **厨房**：油烟机风量 ≥17m³/min（见 `06`），烟道装止逆阀。
- **南方/梅雨**：考虑新风除湿或独立除湿机（湿度＞70% 易发霉）；回南天慎做油漆。
- **北方/干燥**：加湿器或全屋加湿。

## 五、隔音（GB 50118-2010 民用建筑隔声）

| 部位 | 目标 | 做法 |
|------|------|------|
| 分户墙 | 空气声隔声 ≥45dB | 原墙 + 轻钢龙骨隔音棉 + 隔音板 |
| 楼板（邻居脚步） | 撞击声隔声 | 吊顶填隔音棉；地面铺软性材料 |
| 卧室门 | 隔声 ≥30dB | 实木/实木复合门，密封条 |
| 窗 | 隔声 ≥30dB | 断桥铝 + 双层/三层中空玻璃 |
| 下水管 | 排水噪声 | 包隔音棉/隔音毡 |
| 卫生间/厨房 | 管道噪声 | 立管包裹 |

> **临街户型**：优先升级窗户（断桥铝 + 双中空 Low-E），比全屋隔音墙性价比高。

## 六、防潮防霉

- **防水**：卫生间淋浴区上返 ≥1.80m、其他 ≥0.30m；闭水试验 24h（GB 50210-2018）。
- **防潮**：一楼/地下室做全屋防潮层；衣柜背板贴防潮膜。
- **防霉**：硅藻泥/防霉乳胶漆用于潮湿区；柜体留透气孔。
- **通风期**：装修后空置通风 ≥3 个月，有老人小孩/孕妇 ≥6 个月（见 `06`）。

## 七、环境系统方案输出格式

逐系统给出：**是否配置 → 型号参数 → 预埋要求 → 与吊顶/层高的关系 → 验收要点**。示例：

```text
暖通配置（120㎡｜净高 2.85m）
- 中央空调：一拖四多联机，吊顶占用 300mm → 剩余净高 2.55m，满足
- 新风：双向流热回收，主管 150mm 走客餐厅吊顶
- 地暖：不做（已集中供暖）／或水地暖 35–45℃
- 检修口：每台室内机下方预留 450×450 检修口
- 验收：制冷试运行、冷凝水排水试漏、新风风量检测
```

## 八、避坑

1. **吊顶做完才想装中央空调**：为时已晚，必须提前规划。
2. **净高不够硬上吊顶**：压抑且影响采光。
3. **新风当除甲醛**：夸大，甲醛靠通风。
4. **排水管无坡度**：冷凝水倒流泡吊顶。
5. **下水管不包隔音**：楼上冲水听着烦。
6. **临街不换窗**：隔音效果远不如换好窗。
7. **检修口被柜子挡死**：后期维修无处下手。
