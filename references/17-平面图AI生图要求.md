# 平面图 AI 生图（2.5D / 手绘彩平）出图要求

> 适用：调用 ima 自带生图能力（`image_gen`）渲染户型平面渲染图。
> 两种通道：**文生图**（无底图，风险＝布局漂移）｜**图生图 img2img**（以矢量平面/DXF 导出图为底，风险最低，推荐）。

## 一、出图前须备齐的 5 项输入 (口径锁死)

| # | 输入项 | 要求 |
|---|--------|------|
| 1 | **底图** | 矢量平面导出图（`plan_render.py` 产物）或严格尺寸版 PNG，**房间划分/墙体/门窗位置准确** |
| 2 | **房间清单** | 中文房名＋面积（如「客厅 26.4㎡」），须与底图一一对应 |
| 3 | **风格档** | 手绘插画彩平 ／ 2.5D 等轴测 ／ 扁平色块（三选一，勿混） |
| 4 | **色调** | 奶油风锁定：米白 #F5F0E8、浅橡木 #D4C4A8、奶油布艺 #EFE6D8、原木 #C9A87C、绿植点缀 |
| 5 | **标注项** | 房名＋㎡面积、指北针、入户门标识（可选：尺寸标注、家具图例） |

## 二、提示词结构（六段式，逐段必写）

1. **任务**：把这张户型平面图重绘为「X 风格」渲染图，**严格保持房间划分、墙体位置、门窗位置与家具摆放不变**。
2. **视角**：手绘彩平＝正俯视；2.5D＝等轴测俯视约 30°（isometric）。
3. **表现手法**：手绘＝以色代线、无黑描边、哑光平涂、手绘木纹、统一左上方柔和羽化投影；2.5D＝家具立体挤出（顶面＋朝向观察者 1–2 侧面，侧面略深）、右下方柔和投影（暖棕约 30% 半透明）。
4. **配色**：奶油风低饱和色值（见上表）。
5. **家具**：圆润微缩——奶油布艺沙发、蓬松双人床、原木餐桌、通顶衣柜、橱柜、马桶、洗手台、绿植。
6. **标注与画质**：房间名＋㎡用清晰中文小字；**超高清、竖构图、无文字乱码**。

## 三、参数建议

| 参数 | 建议 |
|------|------|
| 通道 | **图生图**（`image` 传矢量底图）优先；纯文生图仅作概念探索 |
| 尺寸 | 竖版 1600×2560 或 1728×2304（与户型竖向一致） |
| 底图 | 若原图偏空，可先由 `plan_render.py` 补全家具再喂图 |
| 出图数 | 一次出 **2–3 版**择优（AI 有一定随机性） |
| 强化词 | 「不要改变布局」「保持墙体与家具位置」「不新增/删除房间」 |

## 四、出图后质检清单（逐项打勾）

- [ ] 房间数量、相对位置与原图一致（错位/漏房即废）
- [ ] 门窗位置对应（入户门、阳台推拉门、各房间门）
- [ ] 中文房名与面积清晰、**无乱码/无错字**
- [ ] 无语义错乱（家具穿墙、洁具叠置、尺寸标注矛盾）
- [ ] 色调统一为指定奶油色系，无明显脏色
- [ ] 视角正确（2.5D 须为等轴测，非纯俯视/非透视）

## 五、已知失败模式与对策

| 失败模式 | 对策 |
|----------|------|
| **布局漂移**（AI 改墙/改房间） | 改走图生图；强化「严格保持布局」；出多版择优 |
| 家具穿墙/重叠 | 先由矢量图摆正再喂图；提示词禁新增家具 |
| 中文乱码 | 提示词强调「中文清晰无乱码」；必要时后期用 Pillow 叠字 |
| 比例失真（房间被拉大/压扁） | 底图保持原纵横比；尺寸锁定 1728×2304 |
| 风格跑偏（变写实照片） | 明确「平面彩平/手绘插画/等轴测」，禁用「照片/写实」 |

## 六、红线

- AI 渲染图为**风格意向**，**不得作为施工/下料依据**；精确布局与尺寸一律以矢量平面图与 DXF 为准。
- 图注须声明「本图为 AI 风格化渲染，仅示意，布局尺寸以图纸为准」。

## 七、平面图家具清单（按逐空间设计要点，图生图时逐条写死）

> 平面图里的家具必须与第五节"逐空间设计要点"一致，否则业主一看就发现"图和方案对不上"。

| 空间 | 平面图必须画成 |
|------|----------------|
| 客厅 | 布艺三人沙发（靠短墙）＋茶几＋**整面通顶书柜墙（不画电视柜）**＋餐桌椅 |
| 主卧 | **1.8m 双人大床**＋通顶衣柜＋书桌（与书柜连体）＋飘窗柜 |
| 儿童房 | **实木上下双层床（上铺带护栏＋梯子）**＋通顶衣柜＋小书桌 |
| 老人房 | **1.5m 实木床**＋推拉衣柜＋飘窗矮柜 |
| 厨房 | 沿长边 L 型/一字橱柜＋冰箱（嵌入高柜） |
| 卫生间×2 | 马桶＋台盆＋淋浴房（客卫含长虹玻璃隔断） |
| 阳台 | 洗烘套装（家政柜）＋洗衣池＋绿植 |

**图生图提示词模板（家具段）**：
> 儿童房改为一组「实木上下双层床」（上下铺、上铺带护栏，靠墙竖向摆放）＋通顶衣柜＋小书桌；老人房＝1.5m 双人床＋衣柜＋飘窗矮柜；主卧＝1.8m 大床＋衣柜＋书桌；客厅＝三人布艺沙发＋茶几＋整面通顶书柜墙＋餐桌椅；厨房＝L 型橱柜＋冰箱；两个卫生间＝马桶＋台盆＋淋浴房；阳台＝洗烘＋家政柜。**其余（房间划分/墙体/门窗/过道/卫生间位置/房间名与面积/指北针/画风）严格保持不变。**

**校验**：出图后与上表逐项核对；儿童房若画成单床即为不合格，重出。
