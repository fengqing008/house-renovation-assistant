## 标准机位规范（每间房两视角·固定机位）

**用法**：每间房固定出两张；第二张提示词前加一句「**与同系列{空间}图同一房间、同一家具布置，仅更换机位**」，再写新机位。

| 空间 | 视角1（机位） | 视角2（机位） |
|------|---------------|---------------|
| 客厅 | 从客厅入口/南端看向沙发 | **从沙发看正对面（西墙通顶书柜墙）** |
| 主卧 | 床位主体 | **从门口向内看** |
| 儿童房 | 双层床＋飘窗书写角 | **从门口向内看（正对双层床）** |
| 老人房 | 床位＋衣柜 | **从门口向内看** |
| 餐厅 | 餐桌正视 | 客厅侧 45° 斜看餐桌＋吊灯 |
| 厨房 | 操作台长边 | 入口纵深方向 |
| 客卫 | 从门口向内看（台盆镜柜＋马桶＋淋浴隔断） | **从门口斜 45° 看**（三者关系） |
| 主卫 | 从门口向内看（双台盆＋淋浴房＋马桶） | **从门口斜 45° 看**（三者关系） |
| 阳台 | **从客厅看阳台（穿透敞开垭口，窗光洒入客厅）** | **从阳台看客厅（垭口敞开通透）** |
| 玄关 | **从客厅看玄关（鞋柜＋入户门）** | **从门口向内看（纵深指向走廊）** |

**机位铁律**：
1. **卧室／卫生间统一"从门口看"**——视角1 正看、视角2 斜看或反向；
2. **阳台两视角须体现"客厅 ↔ 阳台"通透与自然采光**——一从客厅看阳台、一从阳台看客厅（双向对看），提示词须写死"通高垭口敞开、无门扇"，并**严禁把垭口画成实墙或柜体封堵**；
3. **玄关两视角：一从客厅、一从门口**；
4. 同一房间两张图**同一批家具、同一朝向**，仅变机位，出图后互相对照不得矛盾。

**通用写法**：在同房间首张提示词前加「**与同系列{空间}图同一房间、同一家具布置，仅更换机位**」，再用 `image=` 传首张图做 img2img，可最大程度锁住房间几何与家具。

## 平面图 ↔ 效果图 一致性核对（必做）

出图后做一次交叉核对，判定"平面方位 = 效果图方位 = 方案要点"三者是否一致：

| 核对项 | 判定 | 不合格处理 |
|--------|------|-----------|
| 客厅有无电视/电视柜（方案为**去电视化**） | 出现即 ❌ | 重出平面图，提示词显式写"不要电视、不要电视柜" |
| 床的规格（主卧 1.8m / 老人房 1.5m / 儿童房双层床） | 不符即 ❌ | 重出对应图 |
| 飘窗处理（儿童房抬高 750mm；老人房矮柜不抬高；主卧飘窗柜） | 不符即 ❌ | 重出 |
| 靠墙方位（沙发靠短墙、床靠墙、衣柜通顶） | 冲突即 ⚠ | 文案标注"以平面图为准"并重出 |

> 说明：AI 生图对"精确朝向"控制有限，**朝向以矢量平面图/DXF 为准**；效果图仅作风格意向，图注须声明。

## 画幅统一铁律（出图后必做）

**症状**：多张效果图在文档中"**空间错位、尺寸严重失衡**"。
**根因**：AI 直出图的宽高比是随机的（同一房间两张图可能一横一竖、1.75 vs 0.67），**未经统一裁切**就并排排版。

| 项 | 规程 |
|----|------|
| 目标画幅 | 全篇效果图统一 **1400×800（7:4）横版**；同一房间两视角**必须完全同尺寸** |
| 处理方式 | 按目标比例 **居中裁切（cover）**——过宽裁左右、过高裁上下，**禁止拉伸变形** |
| 校验 | 出图后 PIL 批量列出所有图 `size`，出现不一致即 FAIL，**归一后才可成文** |
| 竖版空间 | 卫生间/玄关等小空间易出竖版 → **在提示词中显式写"横构图"**，并指定 `width=1400, height=800` |

```python
from PIL import Image                      # 画幅归一小工具
TW,TH=1400,800; TR=TW/TH
def cover(im):
    im=im.convert('RGB'); w,h=im.size; r=w/h
    box=(((w-int(h*TR))//2,0,(w-int(h*TR))//2+int(h*TR),h) if r>TR
         else (0,(h-int(w/TR))//2,w,(h-int(w/TR))//2+int(w/TR)))
    return im.crop(box).resize((TW,TH),Image.LANCZOS)
# 校验：所有图 size 必须 == (TW,TH)
```

> 交付前**必须**跑一次全量尺寸校验，确认 20 张（10 空间×2 视角）全部 **(1400, 800)**。
