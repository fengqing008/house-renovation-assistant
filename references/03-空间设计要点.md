# 03 · 空间设计要点（S3 逐空间方案·专家版）

> 逐空间给出 **定位 → 布局 → 尺寸校验值 → 材质色彩 → 点位 → 照明 → 收纳 → 避坑**。
> 尺寸依据 GB 50096-2011《住宅设计规范》＋`10-人体工学尺度库`；点位依据 `11-点位系统手册`；照明依据 `12-照明设计手册`。方案中所有尺寸必须标单位，未实测标【待核】。

## 通用红线（硬约束，GB 50096-2011）

| 项目 | 规范要求 |
|------|---------|
| 卧室/起居室室内净高 | ≥2.40m（局部净高 ≥2.10m 且面积 ≤1/3） |
| 过道净宽 | ≥1.00m（通卧室/起居室）；通厨房卫生间 ≥0.90m |
| 厨房操作台净长 | ≥2.10m（单排） |
| 卫生间门宽 | ≥0.70m |
| 楼梯踏步 | 踏面 ≥0.22m、踢面 ≤0.20m |
| 采光窗地比 | 卧室/起居室/厨房 ≥1/7 |

> 校验工具：`python3 scripts/layout_check.py --room 主卧 --width 3.3 --depth 4.2`

## 客餐厅

- **定位**：家庭核心区，兼顾会客、用餐、亲子；动线（入户→客厅→餐厨）不交叉。
- **布局**：小户型客餐厅一体通铺取消隔断；L 型/一字型沙发靠墙，电视墙与投影二选一。
- **尺寸校验**：沙发与茶几间距 0.30–0.45m；沙发前主通道 ≥0.90m；电视中心距地 = 视高（0.93×身高）；餐桌每人宽 ≥0.60m、餐椅后通道 ≥0.75m；餐桌距餐边柜 ≥0.90m。
- **材质色彩**：地面通铺（大板砖/木地板）；墙面浅色；电视背景墙克制（岩板/木格栅/艺术漆）。
- **点位**（见 `11`）：电视墙插座 4–6（藏柜后，高 0.30–0.90m）；沙发两侧各 1–2（高 0.30m）；空调插座 1.80–2.00m；餐边柜 2–3（台面上 0.30m）；餐厅吊灯位。
- **照明**（见 `12`）：基础 100lx／阅读 300lx，色温 3500K，Ra≥90；无主灯（磁吸轨道+筒灯+灯带），分 2 路。
- **收纳**：悬空电视柜、边柜、餐边柜（含酒格/小家电）；收纳量参考 **0.20–0.30m³/㎡建筑面积**。
- **避坑**：①电视墙别做复杂造型（过时积灰）；②插座宁多勿少（沙发两侧、电视墙、餐边柜）；③动线被家具堵死。

## 主卧

- **定位**：休息为主，静音、遮光、收纳三优先。
- **布局**：床头靠实墙；衣柜靠内侧墙；梳妆台/书桌临窗（避逆光）。
- **尺寸校验**：床两侧通道 ≥0.60m（理想 0.70+）；衣柜进深 0.55–0.60m、前操作 ≥0.60m；床头柜宽 ≥0.45m、高与床面齐；通行净宽 ≥0.90m。
- **材质色彩**：木地板、静音门（隔声 ≥30dB）、遮光窗帘（遮光率 ≥85%）；低饱和助眠色。
- **点位**：床头两侧各 2（含 USB，高 0.60–0.70m）；电视/投影 1；空调 1.80–2.00m；梳妆区 1；床头与门口**双控**。
- **照明**：主灯可调光 + 床头壁灯/阅读灯（150lx），色温 2700–3000K，Ra≥90；起夜低位感应灯。
- **收纳**：衣柜顶天立地（避积灰），挂衣区（长衣≥1.40m/短衣≥1.00m）、叠放区、抽屉分区；床下抽屉。
- **避坑**：①床头正对门/镜；②衣柜内部未分区；③灯光过亮影响睡眠。

## 次卧 / 儿童房

- **定位**：次卧兼书房/客房；儿童房强调安全与成长性（见 `14`）。
- **布局**：小户型榻榻米+书桌一体；儿童房圆角家具、活动空间 ≥1.5㎡。
- **尺寸校验**：儿童床护栏高 ≥0.30m；书桌高 0.74–0.76m（可升降）；书架单层板跨 ≤0.90m。
- **材质色彩**：环保优先（儿童房 **ENF** 板材，见 `06`）；色彩活泼不刺激；玻璃钢化。
- **点位**：床头 2；书桌 3–4（电脑/台灯/充电）；空调 1；网口 1。
- **照明**：无频闪护眼灯，书桌照度 300lx，Ra≥90，色温 3500–4000K。
- **收纳**：矮柜+开放格（方便取放）；玩具分类收纳。
- **避坑**：①家具尖角未圆角；②上铺无防护；③板材环保不达标。

## 厨房

- **定位**：高频功能区，动线"洗→切→炒"黄金三角。
- **布局**：一字型/双一字/L 型/U 型，按开间定；灶具与水槽间距 0.6–0.9m，中间留 ≥0.60m 备餐台。
- **尺寸校验**：台面高 0.80–0.85m（**可高低台**：洗涤 0.85–0.90、烹饪 0.75–0.80）；吊柜底距台面 0.60–0.70m、深 0.30–0.35m；单排操作 ≥0.90m、双排间距 ≥1.20m；操作台净长 ≥2.10m。
- **材质色彩**：石英石/岩板台面、防潮板柜体、墙砖到顶；浅色显大。
- **点位**：台面插座 6–8（带开关，台面上 0.30m）；冰箱/洗碗机/微波炉/净水器/垃圾处理器点位；大功率单独回路（4mm²）。
- **照明**：顶灯 100lx + 吊柜下操作灯带 150–300lx，色温 3500–4000K，Ra≥90；操作台面无阴影。
- **收纳**：吊柜+地柜+拉篮+转角飞碟；调味拉篮贴近灶侧；台面下第一层抽屉放餐具。
- **避坑**：①台面高度一刀切（腰累）；②油烟机风量不足（≥17m³/min）；③插座不带开关；④通风/烟道止逆阀。

## 卫生间

- **定位**：干湿分离标配；防水与防滑是底线。
- **布局**：三分离（盥洗/如厕/淋浴）或二分离；马桶距墙 ≥0.30m。
- **尺寸校验**：淋浴区 ≥0.90×0.90m；浴室柜距地 0.80–0.85m；马桶前方 ≥0.45m；干区过道 ≥0.70m（适老见 `14`）。
- **材质色彩**：防滑砖（湿态摩擦系数 ≥0.5）、防水石膏板/铝扣板吊顶；防水：淋浴区上返 ≥1.80m、其他 ≥0.30m。
- **点位**：吹风机 1（防溅盒）、智能马桶 1、热水器 1、洗衣机 1（如需）；全部带防水盒，独立漏保；地漏×2（深水封/T 型）。
- **照明**：顶灯 100lx + 镜前灯 150lx（面部无阴影），色温 3500–4000K，Ra≥90；湿区灯具 IP44 以上。
- **收纳**：镜柜、壁龛、马桶上方置物。
- **避坑**：①防水未做闭水试验（必须 24h）；②地漏选错（返臭，用深水封/T 型）；③无干湿分离，全屋返潮。

## 阳台

- **定位**：生活阳台（洗衣晾晒）或休闲阳台（茶区/花园）。
- **布局**：洗衣区（洗衣机+柜体+晾衣）+绿植区；封窗按物业与气候定。
- **尺寸校验**：洗衣机位宽 ≥0.60m、深 ≥0.60m；晾衣杆高度按身高；休闲区通道 ≥0.60m。
- **材质**：防滑砖、防晒铝板柜体；南方注意排水。
- **点位**：洗衣机 1（1.20m，防水盒）、烘干机 1、电动晾衣架 1、休闲插座 1；地漏 1。
- **照明**：防水吸顶灯 + 氛围灯带，色温 3000–3500K。
- **避坑**：①阳台未做防水直接放洗衣机；②承重限制下堆重物；③封窗违反物业规定。

## 玄关

- **定位**：入户第一印象 + 收纳转换区。
- **布局**：鞋柜+换鞋凳+挂衣区+镜面（显大）。
- **尺寸校验**：鞋柜进深 0.32–0.40m（男鞋 ≤0.32）；底部悬空 0.15–0.20m（放拖鞋）；台面高 0.90–1.05m（放钥匙/包）。
- **点位**：预留 1（消毒/充电）；感应灯带（进门自动亮）。
- **照明**：50–75lx，色温 3000–3500K，感应。
- **收纳**：到顶柜 + 中段台面 + 底部悬空 + 换鞋凳。
- **避坑**：①鞋柜不留透气孔（捂味）；②无换鞋凳；③点到顶。

## 书房 / 多功能间

- **定位**：办公/阅读/临时客房三合一。
- **布局**：书桌临窗避逆光；榻榻米+升降桌（兼客房）。
- **尺寸校验**：书桌高 0.74–0.76m、深 ≥0.55m；容膝空间 ≥0.58m 高；书架单层板跨 ≤0.90m（超则加中立板）。
- **点位**：书桌 4–6（电脑/台灯/充电/网络）；空调 1；网口/AP 位。
- **照明**：桌面 300lx，色温 3500–4000K，Ra≥90，无频闪。
- **避坑**：①书桌正对窗（逆光）；②书架超长无支撑变形。

## 动线与收纳总量估算（方案汇总用）

**动线三原则**：①入户→客厅→餐厨不交叉；②卧室私区与客区分离；③家务动线（厨房—洗衣—晾晒）最短。

**收纳总量经验值**（按建筑面积）：

| 户型 | 收纳总量 | 折算 |
|------|---------|------|
| 90㎡ | 18–24 m³ | 0.20–0.27 m³/㎡ |
| 120㎡ | 26–36 m³ | 0.22–0.30 m³/㎡ |
| 150㎡+ | 34–48 m³ | 0.23–0.32 m³/㎡ |

> 收纳不足是入住后最大痛点；**做方案时先算收纳总量**，再分摊到各空间（玄关/衣柜/橱柜/榻榻米/储物间），列入方案核对表。
