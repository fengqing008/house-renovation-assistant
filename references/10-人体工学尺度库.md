# 10 · 人体工学尺度库（设计校验基准）

> **用途**：S3 方案设计时，所有家具尺寸、通道净宽、台面高度、操作空间均按本表校核；`scripts/layout_check.py` 以此为判据自动校核并输出问题清单。
> **依据**：GB 50096-2011《住宅设计规范》（强制条款）＋人居环境工程通行人体工学尺寸。本表数值为**通行值/经验区间**，落地须按业主身高微调（见第六节换算）。
> **铁律**：方案中每个尺寸必须带单位；未实测的标【待核】，不得凭感觉给精确数。

## 一、人体基本尺寸（一切尺度的出发点）

以家庭成员身高 H 为基准换算（H 取家中主要使用者身高，通常取成人 160–180cm）：

| 关系 | 换算 | 用途 |
|------|------|------|
| 视高 | ≈ H × 0.93 | 电视/挂画/镜面安装高度 |
| 立姿肘高 | ≈ H × 0.63 | 台面/操作面高度基准 |
| 坐姿肘高 | ≈ H × 0.24（坐面上方） | 桌面高度 |
| 坐面高 | ≈ H × 0.25 | 椅凳座高 |
| 摸高（舒适上限） | ≈ H × 1.20 | 吊柜/收纳上层分界 |
| 舒适取物高度带 | 0.75–1.55m | 高频收纳区（黄金区） |

## 二、家具尺度（深 × 宽/长 × 高，单位 m）

| 家具 | 关键尺寸 | 说明 |
|------|---------|------|
| 沙发 | 座高 0.38–0.45、座深 0.48–0.55、扶手高 0.55–0.65 | 座深＞0.60 顶膝、＜0.45 无支撑 |
| 茶几 | 高 0.35–0.45（≤沙发座高） | 与沙发间距 0.30–0.45 |
| 餐桌 | 高 0.72–0.78；每人宽 ≥0.60 | 4 人桌≥1.20×0.80 |
| 餐椅 | 座高 0.42–0.45、拉出后背后通道≥0.75 | 椅面与桌沿高差 0.25–0.30 |
| 书桌 | 高 0.74–0.76、深 ≥0.55 | 下方容膝空间 ≥0.58 高 |
| 双人床 | 1.50×2.00 或 1.80×2.00 | 床面高 0.40–0.50 |
| 床头柜 | 宽 0.40–0.50、高 0.50–0.65 | 与床面齐高或略低 |
| 衣柜 | 进深 0.55–0.60（推拉门 0.60） | 挂衣区高：长衣≥1.40、短衣≥0.90 |
| 鞋柜 | 进深 0.32–0.40（男鞋≤0.32） | 层高 0.15–0.20、底悬空 0.15–0.20 |
| 橱柜地柜 | 深 0.60、台面高 0.80–0.85 | 高低台：洗涤 0.85–0.90、烹饪 0.75–0.80 |
| 橱柜吊柜 | 深 0.30–0.35、底距台面 0.60–0.70 | 顶到吊顶避免积灰 |
| 书柜 | 单层板跨 ≤0.90（超则加中立板） | 层高 0.30–0.35、深 0.28–0.32 |

| 场景 | 最小净宽 | 舒适净宽 | 依据 |

| 床侧通道 | 0.60 | 0.70–0.80 | 通行值 |
| 沙发前到茶几 | 0.30 | 0.40–0.45 | 通行值 |
| 餐椅后通道（拉出落座） | 0.75 | 0.90 | 通行值 |
| 衣柜前操作（平开/推拉） | 0.60 | 0.75–0.90 | 通行值 |
| 厨房单排操作 | 0.90 | 1.00–1.10 | 通行值 |
| 厨房双排/岛台间距 | 1.20 | 1.30–1.50 | 通行值 |
| 卫生间干区过道 | 0.70 | 0.80 | 通行值 |
| 淋浴区 | 0.90×0.90 | 1.00×1.00 | 通行值 |
| 马桶前方 | 0.45 | 0.55–0.60 | 通行值 |
| 洗手台前站立 | 0.60 | 0.75 | 通行值 |

> **厨房黄金三角（洗→切→炒）**：水槽—操作台—灶具三点连线总长宜 3.6–6.0m，任两点间距 0.6–2.7m；水槽与灶具之间必须留 ≥0.60m 备餐台。

## 四、柜体内部黄金分区

- **衣柜**：上区（≥2.0m，放换季/被褥）／中区黄金区（0.75–1.75m，挂衣、抽屉）／下区（≤0.75m，叠放、抽屉、鞋）。挂衣杆高：长衣 ≥1.40m、短衣 ≥1.00m；抽屉高度 ≤0.25m 便于俯视。
- **橱柜**：台面下第一层抽屉放餐具（俯视可见），拉篮放锅具（转角用飞碟/小怪物），调味拉篮贴近灶侧。
- **玄关柜**：底部悬空 0.15–0.20 放常穿鞋；中段留台面（放钥匙/包）高 0.90–1.05；上柜到顶。

## 六、按身高换算台面高度（避免"一刀切"腰累）

厨房台面高度 = 使用者身高 × 0.5 ÷ 2.54 ≈ 身高（cm）× 0.20（cm）。通行分档：

| 使用者身高 | 洗涤区台面高 | 烹饪区台面高 |
|-----------|-------------|-------------|
| ≤155cm | 0.80 | 0.72 |
| 155–165cm | 0.85 | 0.76 |
| 165–175cm | 0.88 | 0.78 |
| 175–185cm | 0.92 | 0.80 |
| ≥185cm | 0.95 | 0.83 |

> 全屋下厨者身高差＞10cm 时，建议做**高低台**（洗涤高、烹饪低），综合最优。

## 七、常见错误对照（校核重点）

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 台面高度一刀切 | 洗菜弯腰、炒菜架胳膊 | 高低台或按身高定制 |
| 床侧通道 <0.60 | 无法铺床/通行 | ≥0.60，理想 0.70+ |
| 沙发与茶几过近 <0.30 | 无法通行、碰腿 | 0.30–0.45 |
| 吊柜做到顶却够不着 | 上层闲置 | 上存换季/低频物 |
| 电视中心过高 | 仰头疲劳 | 视高 0.93H，坐姿视线略下 |
| 餐桌后不留通道 | 拉椅碰墙 | ≥0.75（拉出+落座） |

## 八、校验方式

```bash
python3 scripts/layout_check.py --room 厨房 --width 1.8 --depth 2.7 --type L型
```

输出：逐项对照本库判据，列出**低于下限（❌）／处于下限（⚠）／达标（✅）**，并给出调整建议。
