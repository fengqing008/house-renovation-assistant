# 01 · 风格图鉴（8 种主流风格全要素）

> 用于 S1 风格判定与 S3 风格化方案。每种风格给出**关键色（hex）→ 材质 → 家具 → 灯光 → 软装 → 适用人群 → 避坑**七要素，方案中引用时必须落到具体色号与材质名，不停留在"温馨""高级"这类形容词。

---

## 一、现代简约（Modern Minimal）

- **定位**：少即是多，靠比例、留白与材质对比取胜。最百搭、最不易过时。
- **关键色**：墙面 `#F5F5F3`（暖白）/ `#FFFFFF`；主色 `#4A4A48`（深灰）；点缀 `#B8B0A0`（暖米）。三色以内。
- **材质**：哑光大板砖/微水泥、白色乳胶漆、金属细框（黑钛/拉丝铝）、超白玻璃、浅色木饰面。
- **家具**：直线条、低矮重心、细腿悬空款（便于扫地机器人）；隐藏式收纳。
- **灯光**：无主灯（磁吸轨道+线性灯+防眩筒灯），色温 3500-4000K，重点照明打亮材质。
- **软装**：几何抽象画、纯色织物、绿植龟背竹/散尾葵。
- **适用**：年轻首置、小户型显大、追求好打理。
- **避坑**：无主灯设计对层高要求高（净高＜2.6m 慎用大吊顶）；纯白太冷需配暖色木与织物中和；低质量金属框易显廉价，认准拉丝工艺与阳极氧化。

## 二、奶油风（Cream Style）

- **定位**：柔和治愈，低饱和奶油色系 + 圆润造型，2021 年后最热风格，适合小家庭与亲子。
- **关键色**：主色 `#F1E4D6`（奶油杏）、`#EFE6DA`（奶咖）；搭配 `#D9C7B0`（浅燕麦）；点缀 `#C8B39E`。
- **材质**：奶油色哑光砖/木纹砖、艺术涂料、弧形造型墙、亚麻布艺、羊羔绒。
- **家具**：圆弧倒角、无棱角、奶白+原木混搭，沙发选"胖胖款"。
- **灯光**：暖光 3000K，灯带洗墙，蜡烛灯/云朵灯。
- **软装**：奶油色窗帘（加遮光衬布）、藤编、干花、暖色地毯。
- **适用**：新婚、亲子家庭、想要温馨治愈。
- **避坑**：奶油色全屋易"一片糊"，须靠**深浅对比与材质层次**（亚麻/绒布/木纹）区分；不耐脏，选可擦洗涂料与耐脏布艺；阴天易发灰，要保证采光或加大照明。

## 三、新中式（New Chinese）

- **定位**：传统神韵 + 现代手法，对称、留白、借景，文化感强。
- **关键色**：主色 `#E8E2D5`（月白）、`#7C6A58`（胡桃木）；点缀 `#8B4A3B`（朱砂红）/ `#3C4A46`（黛绿）/ `#1C1C1C`（墨）。
- **材质**：胡桃木/黑檀木饰面、岩板、水墨石材、丝绢、铜件。
- **家具**：圈椅改良款、条案、博古架、明式简约线条；对称布局。
- **灯光**：格栅灯、灯笼造型、暖光洗墙，讲究"见光不见灯"。
- **软装**：水墨挂画、青瓷摆件、屏风、禅意绿植（罗汉松/南天竹）。
- **适用**：注重文化品位、长辈家庭、大平层/别墅。
- **避坑**：不是"堆传统符号"，忌繁复雕花；小户型慎用深木色（显压抑）；红木不宜用满屋，点缀为宜。

## 四、日式原木（Japanese Muji）

- **定位**：自然、本真、收纳至上，"住着松弛"。
- **关键色**：主色 `#EFEAD8`（米白）、`#C9A86A`（浅橡/白蜡木）；点缀 `#8B8B7A`（灰绿）。
- **材质**：白蜡木/橡木/松木（哑光开放漆）、棉麻、席纹、纸障子（可选）。
- **家具**：矮家具、悬空电视柜、榻榻米、格栅门。
- **灯光**：暖光 2700-3000K、纸灯/和室灯、顶部间接照明。
- **软装**：无印风棉麻、藤编收纳、苔藓/绿植、简约陶器。
- **适用**：小家庭、注重收纳与自然感。
- **避坑**：原木色差要统一（同批次同树种）；开放漆怕水，厨卫慎用；实木需防潮防虫。

## 五、侘寂风（Wabi-sabi）

- **定位**：残缺、朴素、自然肌理，微水泥+原生态材质，艺术感强。
- **关键色**：主色 `#E5E0D5`（燕麦）、`#B9B0A0`（灰米）、`#9A9384`（灰褐）；点缀 `#6B6459`。
- **材质**：微水泥、夯土墙、手工陶砖、亚麻、黄铜旧化、原木（保留结疤）。
- **家具**：粗粝质感、异形陶器、藤麻编织、手工感灯具。
- **灯光**：极暗调、间接光、局部重点光，营造静谧。
- **软装**：手工陶、枯枝、天然石材、艺术涂料肌理。
- **适用**：追求艺术感与静谧、独居/情侣、中式酒店风爱好者。
- **避坑**：微水泥施工要求高（基层处理+多道工序），易开裂返修；整体偏暗，须保证采光；造价高，慎追低价施工。

## 六、工业风（Industrial）

- **定位**：裸露、粗犷、金属+砖石+原木的碰撞，Loft 感。
- **关键色**：主色 `#3B3B3B`（炭黑）、`#6E6259`（做旧砖）；点缀 `#B8860B`（黄铜）/ `#4A5D52`（墨绿）。
- **材质**：水泥自流平/水泥漆、红砖/文化砖、黑铁、实木、皮革、玻璃。
- **家具**：金属框架、皮质沙发、复古工业灯具、铁艺置物架。
- **灯光**：爱迪生灯泡、轨道灯、黑铁吊灯。
- **软装**：复古海报、皮质单品、机械钟表、绿植。
- **适用**：Loft/高厅、单身/情侣、追求个性。
- **避坑**：裸露管线需规划整齐且防锈处理；水泥地面易返砂起尘，须做固化；不适合小户型（显拥挤压抑）。

## 七、法式轻奢（French Chic）

- **定位**：优雅浪漫 + 精致线条，石膏线/护墙板+金色点缀。
- **关键色**：主色 `#F3EFE9`（象牙白）、`#E6DED2`；点缀 `#C9A227`（香槟金）/ `#8C7B6B`（莫兰迪灰棕）。
- **材质**：石膏线/护墙板、大理石、人字拼木地板、丝绒、黄铜。
- **家具**：弧线、雕花（简化）、绒面沙发、金属腿单椅。
- **灯光**：水晶/玻璃吊灯、壁灯、暖光。
- **软装**：丝绒窗帘、油画、大理石台面、金框镜。
- **适用**：注重浪漫仪式感、大户型、女性偏好。
- **避坑**：石膏线要"点到为止"，满墙线脚显廉；金色占比＜15%，否则俗气；绒布易积灰。

## 八、北欧（Nordic）

- **定位**：简洁、明亮、功能主义，浅色+跳色，性价比高。
- **关键色**：主色 `#FFFFFF` + `#E9E7E2`；跳色 `#5B8C85`（雾绿）/ `#D98C5F`（暖橘）/ `#3E5C76`（雾蓝）。
- **材质**：浅色木地板、白墙、棉麻、羊毛、软木。
- **家具**：宜家风格原木家具、布艺沙发、几何纹样。
- **灯光**：多灯具组合（吊灯+落地灯+台灯），暖白光。
- **软装**：几何抱枕、羊毛毯、绿植、装饰画墙。
- **适用**：年轻家庭、预算中等、追求清爽。
- **避坑**：大面积纯白显冷清，需暖木与织物中和；跳色不宜多（≤2 种）；廉价刨花板家具易变形。

## 九、中古风（Mid-century Modern）

- **定位**：20 世纪中叶复古调，胡桃木 + 黄铜 + 皮革 + 布艺，低矮家具与饱满曲线。
- **关键色**：主色 `#E8DFD0`（米灰）、`#6B4F3A`（胡桃木）；点缀 `#C08A2E`（黄铜）/ `#8C3B2E`（砖红）/ `#4A5D52`（墨绿）。
- **材质**：胡桃木/柚木、黄铜、皮革、羊毛、玻璃砖。
- **家具**：低矮细腿沙发（伊姆斯/丹麦风）、异形茶几、弧形单椅。
- **灯光**：黄铜吊灯、球形壁灯、暖光 2700K。
- **软装**：几何地毯、复古海报、陶罐、绿植。
- **适用**：追求复古质感与设计感、中度预算。
- **避坑**：颜色一多易乱，控制 3 主色以内；仿品廉价感强，认准木皮质感；小户型慎用深木色。

## 十、原木极简（Japandi）

- **定位**：日式与北欧的融合，极简线条 + 原木肌理 + 克制留白，温润不冷。
- **关键色**：主色 `#F2EFE9`（暖白）、`#D6C4A8`（橡木）；点缀 `#9AA08C`（灰绿）。
- **材质**：橡木/白蜡木、微水泥、棉麻、藤编、哑光五金。
- **家具**：低矮原木家具、无把手一体柜、细腿悬空款。
- **灯光**：无主灯 + 间接光，暖白 3000K，见光不见灯。
- **软装**：素色织物、陶器、少量绿植。
- **适用**：小户型显大、追求高级感又不想冷、预算中等偏上。
- **避坑**：极简最忌杂物外露，必须做强收纳；原木色差要统一；墙面留白需灯光层次，否则呆板。

## 十一、法式田园（French Country）

- **定位**：自然浪漫的乡村法式，碎花、藤编、做旧木与柔和色调。
- **关键色**：主色 `#F5EFE3`（奶白）、`#C8D6C0`（鼠尾草绿）；点缀 `#C4807A`（干玫瑰）/ `#B79A6B`（做旧金）。
- **材质**：做旧实木、藤编、碎花布艺、复古砖、铜件。
- **家具**：弧形木质餐椅、藤编柜、带褶皱布艺沙发。
- **灯光**：铁艺枝形吊灯、暖光壁灯。
- **软装**：碎花窗帘、陶器、干花、编织筐。
- **适用**：女性偏好、别墅/大户型、向往自然田园。
- **避坑**：碎花与花纹忌满屋铺，需留白；做旧不等于破旧；藤编需防潮。

## 十二、美式复古（American Vintage）

- **定位**：厚重、温暖、沉稳的美式经典，实木 + 皮革 + 铆钉 + 深色系。
- **关键色**：主色 `#EDE6DA`（米白）、`#5B4636`（胡桃木/深棕）；点缀 `#7D2E2A`（酒红）/ `#2F4F4F`（深墨绿）。
- **材质**：实木、全粒面皮革、黄铜五金、亚麻、地毯。
- **家具**：铆钉皮沙发、实木餐桌、四柱床。
- **灯光**：铁艺/黄铜吊灯、台灯，暖光。
- **软装**：波斯/几何地毯、皮质单品、书架、油画。
- **适用**：追求沉稳质感、大户型、三代同堂。
- **避坑**：深色吸光，小户型慎用；皮革需打理；实木需防潮防裂。
